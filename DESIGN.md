# CyberArk L2 Rolebook — Design Direction

## Design Read

This is an offline learning and reference workspace for L2 support engineers. The interface should feel like a security operations field manual: calm enough for long reading, structured enough for investigation, and specific to CyberArk support work rather than a generic SaaS dashboard.

## Dials

- ENERGY 2 — teal is reserved for active states, progress, and the primary action; amber is reserved for warnings.
- RHYTHM 3 — long-form reading, metric summaries, module coordinates, and evidence rails create deliberate changes in density.
- MOTION 1 — transitions communicate state changes only; no floating cards, bounce, glow, or decorative parallax.

## Visual Language

- Identity motif: evidence rails and operational coordinates (`M01`, scope, time, change).
- Palette: dark green-black navigation, paper-like surfaces, CyberArk teal, and a single amber warning accent.
- Typography: readable system sans for content; monospace only for coordinates, labels, and operational metadata.
- Components: square-edged panels and controls, status tags only where they communicate state, and borders instead of generic elevation.

## Anti-Slop Decisions

- No blue-purple gradient, decorative glassmorphism, universal glow, or universal card hover animation.
- No invented testimonials, customer claims, or marketing proof points.
- Interactive controls keep a direct label and preserve keyboard focus states.
- The theme is a filter layered over the existing functional UI; it does not replace the reader, quiz, scenario, notes, progress, or reference workflows.
