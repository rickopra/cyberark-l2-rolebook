# IDIRA L2 Rolebook (formerly CyberArk)

A static offline-first learning workspace made by Ricko Prayudha for PAM L2 support. The product label in the interface is **IDIRA (formerly CyberArk)** while legacy component, file, object, and command names remain unchanged where they are technically required.

## PAM Administrator curriculum

- 20 self-contained Indonesian chapters mapped against all 699 pages of the local PAM Administration training bundle.
- 46,000+ rendered study words across the 20 chapters.
- 87 source addenda covering exact commands, parameters, ports, limits, built-in objects, and workflow details.
- 70 clearly labeled Rolebook analysis sections covering architecture, application, troubleshooting, automation, maturity, and reusable artifacts.
- Curriculum and Library contain the complete explanations; the learner does not need to return to the PPT/PDF.
- Library search indexes article aliases and full section content, including terms such as `RecPrvKey`, `AllowedSafes`, `PADR.ini`, and `ITATS004E`.

## Public version

This repository is designed to run as a static GitHub Pages site. Progress uses browser storage on hosted pages; the local PowerShell launcher remains available for folder-based progress sync.

The public bundle intentionally excludes local progress, server lock files, raw subtitle transcripts, and local PDF/DOCX source files.

## Local use

Run `Open CyberArk Rolebook.cmd` or `Open CyberArk Rolebook.vbs` for the local experience.

The local server exposes folder-based progress sync and serves the complete M01-M20 chapter/addendum bundle.

## CyberBrainer companion

Open **Library** and search for `CyberBrainer`, or open **Curriculum > Video Companion > M15**. The notes are paraphrased study material; official documentation and customer runbooks take precedence for version-specific execution.
