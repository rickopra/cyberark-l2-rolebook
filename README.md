# CyberArk L2 Rolebook

A static learning workspace for CyberArk PAM L2 support. The Library includes structured, paraphrased study notes from the 10-video CyberBrainer tutorial series.

## Public version

This repository is designed to run as a static GitHub Pages site. Progress uses browser storage on hosted pages; the local PowerShell launcher remains available for folder-based progress sync.

The public bundle intentionally excludes local progress, server lock files, raw subtitle transcripts, and local PDF/DOCX reference files.

## Local use

Run `Open CyberArk Rolebook.cmd` or `Open CyberArk Rolebook.vbs` for the local experience.

## CyberBrainer companion

Open **Library** and search for `CyberBrainer`, or open **Curriculum → Video Companion → M15**. The notes are paraphrased study material; official CyberArk documentation and customer runbooks take precedence for version-specific execution.
